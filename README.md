# Kinetix 🌍✈️

**Kinetix** is an AI-powered trip planner that helps you generate dynamic, personalized itineraries and travel schedules. Built with a modern full-stack architecture featuring a responsive JavaScript frontend and a robust Python backend.

## 🚀 Features

- **Automated Itinerary Generation:** Tailors multi-day travel plans based on your preferences.
- **Full-Stack Architecture:** Seamless integration between a Vite-powered JS frontend and a Python backend.
- **Containerized Deployment:** Ready to run anywhere out of the box with Docker Compose.

## 🛠️ Tech Stack

- **Frontend:** JavaScript, HTML, Vite
- **Backend:** Python
- **Runtime & Tooling:** Node.js, Docker, Docker Compose
